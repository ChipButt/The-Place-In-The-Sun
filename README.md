# Roll Britannia: Nassau Prototype v0.14

Mobile-first tile RPG prototype.

## This version adds/fixes

- Chicken walk animation now moves during the walk step, then idles instead of walking in place.
- Chickens start on staggered timers so they do not all animate together.
- Removed the opening “continue” dialogue after character selection.
- NPCs can only be spoken to from the tile directly in front of them while facing them.
- Signs/plaque interactions now require standing above or below the sign and facing it.
- First hut is now enterable and loads a third map/interior.
- No chickens spawn in the house interior.
- Added one local save slot.
- Start screen now has Load Save Game and Play New Game.
- Starting a new game when a save exists warns that it will erase the current save.
- Save currently uses browser localStorage on the device.
