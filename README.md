# Royal Britannia: Nassau Prototype v0.11

Mobile-first tile RPG prototype.

## Added in v0.11

- Added simple repeatable grind mechanic.
- Added Nancy the tavern keeper on Nassau.
- Nancy says: “Hello my lovelies, how can I help you today then?”
- Nancy buys 1 egg for 2 GP.
- Nancy buys 2 wheat + 2 barley together for 5 GP.
- Added chickens to Nassau only; chickens are not placed in caves.
- Chickens roam and occasionally lay eggs.
- Eggs can be collected with the ACT button when nearby.
- Added wheat/barley resource counters in the right-hand inventory panel.
- Walking through flower tiles can occasionally find 1 wheat or 1 barley.
- Crops can only be planted on grass tiles.
- Press ACT while standing on a grass tile to plant wheat/barley if you have one.
- 1 planted crop harvests into 3 of that crop.
- Crops take a short prototype growth time before harvesting.

## Uploading

Upload the contents of this ZIP directly to the root of your GitHub repository.
