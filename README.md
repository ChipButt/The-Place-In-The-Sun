# Royal Britannia: Nassau Prototype v0.10

Mobile-first tile RPG prototype.

## v0.10 changes

- NPCs and signs now block movement on their own tile.
- Canvas tap-to-interact is disabled; use ACT / E / Enter / Space only.
- Concerned Citizen and Old Lost Pirate now move tile-by-tile rather than sliding freely.
- Old Lost Pirate waits until the player presses Continue before leaving the cave.
- Old Lost Pirate walks around the player before leaving the cave.
- Right-panel pocket labels have been removed and the quick inventory has been tightened.
- Cave mouth collision now blocks all cave tiles except the bottom-middle entrance tile.
- Added an Old Smuggler's Cave plaque/sign next to the cave entrance.
- Removed the hut-wide text interaction; the hut now uses a plaque next to the door.
- Concerned Citizen walks fully to the hut door after the key quest is completed.
- Cave maze has been made slightly more involved.
- Loot panel now removes item squares as items are taken and closes once emptied.

## Controls

Desktop:
- Move: WASD / Arrow keys
- Act: E / Enter / Space
- Bag: I / B

Mobile:
- Move: right-side D-pad
- Act: centre ACT button

Upload the contents of this ZIP directly to the repository root.
